JS идет сначала сверху вниз, читает все Объявления ПЕРЕМЕННЫХ а потом начинает выполнять код построчно. 
Пр-р:
1. var a = 5
2. console.log(a) // В DevTools будет 5, а если строки наоборот то будет Underfiend. Потому что js увидел сначала var переменную.
1. var a; // Объявление поднято вверх
2. console.log(a); // когда вызываем консольлог мы еще не дошли до кода где мы присваиваем ей значение, поэтому здесь Underfiend.
3. var a = 5
4. console.log(a); // а когда мы консольлог выведем после var а = 5, то здесь уже js дошёл до var a = 5, то здесь он уже выводит 5.

ПО ФАКТУ! 
1. console.log(a) // это ошибка
2. const a = 5; // это ошибка
исключением явл-ся переменная var
1. console.log(a) // обращение к переменной
2. var a = 5; // п.ч. js помечает её как уже созданную, но при этом не добавляет это знч (5). В DevTools будет Underfiend.
// Важно! Сначала объявляем переменную, и затем к ней обращ-мся.
